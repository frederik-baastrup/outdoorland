# Outdoorland

Outdoorudstyr til camping, vandring, fiskeri og jagt fra flere danske shops samlet ét sted (outdoorland.dk). Samme kodebase som Kitzhen, Fitbase og Pizzalicious; nichen er sat op i `wp-content/plugins/playform-feeds/src/Config.php`. WordPress + WooCommerce med et eget importplugin og et eget tema.

Se `CLAUDE.md` for opbygning, regler og udrulning.
